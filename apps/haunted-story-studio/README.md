# Haunted Story Studio (Built on Skeleton Crew Boilerplate)

A collaborative interactive ghost-story co-writer built directly from `../../template`.

## What Was Customized From the Skeleton

- **Theme & Branding (`src/lib/app-config.ts`)**: Switched palette to midnight purple and pumpkin orange.
- **Story Modes (`src/lib/app-config.ts`)**: Added `Victorian Manor`, `Abandoned Subway`, and `Cursed Git Repo` narrator personas.
- **Story Export (`enableMarkdownExport: true`)**: Export your finished horror story directly as `haunted-story.md`.

## Run Locally

```bash
cp .env.example .env.local
npm install
npm run dev
```
